# IRCTC Sprint

This repository contains design sprint deliverables for improving the IRCTC train booking experience.

## Repository structure

- `part-a/PROBLEMS.md` — problem discovery and evidence-backed issue statements
- `part-b/SPECS.md` — solution specifications mapped to Part A problems
- `part-b/WIREFRAMES.md` — UI wireframes and interaction flows
- `part-b/MATRIX.md` — impact vs effort prioritization matrix
- `part-b/AI-FEATURE.md` — AI feature proposal
- `part-b/README.md` — summary of Part B deliverables
- `part-b/COMPLETION-SUMMARY.md` — sprint completion overview
- `assets/screenshots/` — reference screenshots

## Getting started

1. Read `part-a/PROBLEMS.md` for problem context.
2. Review `part-b/SPECS.md` and `part-b/MATRIX.md` for the proposed solution plan.
3. Use `part-b/WIREFRAMES.md` and `part-b/AI-FEATURE.md` for implementation direction and design details.
