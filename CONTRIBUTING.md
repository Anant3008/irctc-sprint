# Contributing Guidelines

Thanks for contributing to this IRCTC sprint repository.

## Scope

This repository is primarily documentation-driven. Contributions should improve:

- problem clarity and evidence quality
- solution specs and traceability
- wireframes and prioritization rationale
- formatting and consistency across docs

## How to contribute

1. Create focused, minimal changes.
2. Keep updates consistent with existing document structure and tone.
3. Preserve traceability between Part A problems and Part B solutions.
4. Avoid unrelated churn in the same pull request.

## Pull request checklist

- [ ] Changes are limited to the intended scope.
- [ ] Updated sections remain consistent with linked files.
- [ ] Markdown formatting is clean and readable.
- [ ] No sensitive or private data is introduced.
